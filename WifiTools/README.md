# أدوات الواي فاي (WifiTools)

تطبيق أندرويد (Kotlin) فيه:
1. اسم الشبكة وتفاصيلها (قوة الإشارة، التردد، القناة، IP، الراوتر، DNS)
2. قياس سرعة الشبكة (Ping / تحميل / رفع)
3. عدد الأجهزة على الشبكة وقائمة بعناوينها
4. فتح صفحة الراوتر لإعادة تشغيله

## طريقة الحصول على الـ APK

### الطريقة الأسهل: GitHub Actions (من غير ما تنزّل حاجة)
1. اعمل repository جديد على GitHub وارفع محتوى المجلد ده.
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
3. بعد دقيقتين تلاتة نزّل `WifiTools-APK` من قسم Artifacts، وجواه `app-debug.apk`.

### أو من Android Studio
افتح المجلد ← انتظر Sync ← **Build > Build APK(s)**.
الملف هيظهر في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات مهمة
- **اسم الشبكة**: أندرويد بيشترط إذن الموقع وتشغيل الـ GPS علشان يظهر الـ SSID.
- **عدد الأجهزة**: الفحص بيعتمد على ردّ الأجهزة، فالأجهزة النايمة أو اللي عليها حماية ممكن متظهرش (الرقم تقريبي).
- **إعادة تشغيل الراوتر**: مفيش API موحد في أندرويد لده. التطبيق بيفتح صفحة الراوتر جوه التطبيق وانت بتسجل الدخول وتدوس Reboot. التطبيق مبيحفظش أي يوزر أو باسورد.
- قياس السرعة بيستخدم سيرفرات Cloudflare العامة وبيستهلك حوالي 30–40 ميجا.
